# Синтетический демонстрационный набор

`sessions_synthetic.csv` — полностью выдуманные сессии для 16 условных коров.
Это отдельная симуляция, не дополненная выгрузка Supabase и не восстановленные
экспериментальные измерения. Каждая строка имеет `is_synthetic=true`,
`provenance=synthetic_simulation`, идентификаторы `SYN_…` и метки `SYN_COW_…`.
В статье набор пригоден для иллюстрации обработки данных с подписью
«синтетический сценарий», а не для подтверждения фактических надоев и точности системы.

Допущения сценария:

- Период: 17 мая — 21 сентября 2026 года, местное время UTC+05:00.
- Ровно 16 условных коров, два доения в день, четыре устройства.
- **24 июня — 10 июля включительно: записей нет (17 дней).** Это выбранный
  сценарий перерыва, а не подтверждение реального участия инженеров.
- В остальные дни независимо пропускается около 2,5% сессий для имитации потерь
  регистрации; отсутствие записи не означает отсутствие доения или нулевой надой.
- Индивидуальные уровни продуктивности, постепенный спад, связанные между днями
  колебания и разница между утренним и вечерним доением заданы моделью.
  Эти параметры не оценивались по реальному стаду и не прошли биологическую валидацию.
- Начальный суточный уровень задан в пределах 10,5–18,5 кг; случайные колебания
  могут выводить отдельные сутки за этот диапазон. Погодные эффекты не моделировались.
- Начальный и конечный вес в кг, весовой журнал в граммах, время журнала — секунды
  от начала. `milk_mass_kg` равен разности конечного и начального веса.
- Каждый сеанс моделирует отдельное взвешивание; смена бидона внутри сеанса
  не моделируется, `end_reason=0`. Дистанции оставлены пустыми.

`synthetic_daily_coverage.csv` содержит полный календарь, включая перерыв.
`sessions_synthetic.meta.json` фиксирует допущения и seed генератора.
Исходный `sessions_rows.csv` не изменяется.

Повторное создание (Python 3, стандартная библиотека):

```bash
python generate_synthetic_sessions.py
```

Команда перезаписывает только три файла результатов симуляции.
